Platform Documentation & User Guide

v1.1 — February 2026

Platform Overview

Xenon ERP is a centralized inventory management platform built on Laravel. It serves as the single source of truth for product catalog data across multiple sales channels including OpenCart storefronts, Lazada, and Shopee.

Centralized Catalog

Manage products, categories, manufacturers, and options from one place.

Multi-Store Sync

Push product data to multiple OpenCart stores and pull orders back.

Lazada Integration

List products, manage orders, and handle fulfillment directly.

Stock Management

Automatic inventory adjustment based on order status changes.

Role-Based Access

Granular permissions for different user roles and teams.

Sales Analytics

Dashboard with revenue charts, order stats, and quick links.

Dashboard

The dashboard provides a quick overview of your business performance.

Stat Cards

Four cards at the top display key metrics:

  • Total Orders — Count of all orders in the system.
  • Total Revenue — Sum of all order totals (PHP).
  • Total Products — Count of all catalog products.
  • Lazada Pending — Count of Lazada orders awaiting action (highlighted in red if any).

Sales Chart

An interactive chart shows revenue (bar) and order count (line) over time. Switch between three views:

  • 30 Days — Daily breakdown for the last month (default).
  • Monthly — Monthly totals for the last 12 months.
  • Yearly — Annual totals for the last 5 years.

Add product variants such as Color, Size, or Material.

Order Sync & Cronjob

Order Sync Settings

Each store has two ways to control how far back the sync fetches orders. This avoids re-processing old orders every time and significantly speeds up sync operations.

SettingDescription
Sync Last N DaysA rolling window (e.g., 7). The cronjob always fetches orders from the last N days. Every day, it looks back the same number of days — the window never grows. Recommended for cronjobs.
Fixed DateA specific date (e.g., Jan 1, 2026). Orders modified on or after that date are fetched. Useful for one-time pulls or specific date ranges. The window grows each day.
Priority If both are set, Sync Last N Days takes priority and the fixed date is ignored. Set "Sync Last N Days" to 7 for a typical cronjob — this covers daily orders plus a safety overlap for delayed updates.
ScenarioBehavior
Sync Last N Days = 7Cronjob always fetches orders from the last 7 days. Same window every day.
Fixed Date = Jan 1, 2026Fetches all orders since Jan 1. Window grows daily.
Neither setAll orders are fetched from the beginning. A warning is displayed.
Initial Import buttonAlways fetches all orders regardless of either setting.

Configure these in the Order Sync section of each store card and click Save. You can also click Pull Orders Now to manually trigger a sync at any time.

Cronjob Setup

To automate order syncing, set up a cronjob in your hosting panel using the provided wget command.

Navigate to your hosting panel (cPanel, DirectAdmin, etc.) and find Cron Jobs or Scheduled Tasks.
Set the interval. Recommended: every 15 minutes (*/15 * * * *) or every 30 minutes (*/30 * * * *).
Copy the wget command from the Cronjob Setup section on the settings page (click the Copy button).
Paste the command into the command field in your hosting panel and save.

Two cronjob commands are provided per store:

  • This store only — Syncs orders for a single specific store.
  • All enabled stores — Syncs orders for every enabled store in one call.
Security The cronjob URL includes your application key for authentication. Do not share it publicly. The endpoint does not require login — it authenticates via the key parameter.

Profiles

OpenCart Profiles let you organize products into groups and selectively push them to a specific OpenCart store. Each enabled store has its own set of profiles, accessible from the sidebar.

Creating a Profile

Click an OpenCart store name in the sidebar (e.g., "Shop A") to go to the profile list.
Click Add Profile.
Enter a profile name (e.g., "Guitar Pedals", "Drum Kits").
Optionally select categories and/or manufacturers to filter which products belong to this profile.
Click Create Profile. The matching product count is displayed.

Product Matching

Products are included in a profile through two methods:

  • Filter-matched — Products automatically included based on the profile's category and manufacturer filters. Shown with a "Filter" tag.
  • Manually added — Individual products added by searching for them. Shown with a "Manual" tag.

Viewing & Pushing Products

From the profile list, click Products to see all matching products in a table with image, name, SKU, price, quantity, status, and push status (whether it already exists in the OpenCart store).

  • Push Selected — Select products using checkboxes and click "Push Selected" to sync them to the OpenCart store.
  • Add Products — Search by name, SKU, or model to manually add individual products to the profile.
  • Remove — Remove manually-added products from the profile.
Use Case If you have multiple OpenCart stores carrying different product lines, create profiles to control exactly which products go to which store. For example, "Shop A" might get guitars while "Shop B" gets keyboards.

Quick Actions

Each enabled store card provides:

Initial Import (One-Time)

Under Quick Actions, click Initial Import to expand the full import panel. These buttons ignore the date filter and fetch all data from the beginning. Typically used only once during onboarding:

  • Categories — Import categories with full parent-child hierarchy.
  • Manufacturers — Import manufacturer/brand list.
  • Options — Import option definitions and their values.
  • Products — Import all products with descriptions, images, options, specials, and categories.
  • Orders — Import all orders from the beginning.
Source of Truth After initial import, Xenon becomes the source of truth. All catalog changes should be made in Xenon and pushed to OpenCart stores, not the other way around.

How Product Sync Works

  • Matching: Products are matched between Xenon and OpenCart by SKU. Each linked product is tracked in a product links table.
  • Push (new product): If a Xenon product has no link to the OpenCart store, a new product is created in OpenCart. Categories, manufacturers, and options are resolved by name — if they don't exist in OpenCart, they are created automatically.
  • Push (existing product): If a link exists, the product is updated with the latest quantity, price, status, name, description, and other fields.
  • Each store has its own IDs: OpenCart products have their own auto-increment IDs. The link table maps between Xenon and OpenCart IDs per store.

Sync Log

At the bottom of the settings page, a table shows recent sync operations with date, store, entity type, direction (pull/push), status, records processed/created/updated/failed, duration, and error messages.

Scheduled Sync

Order syncing is automated via a wget-based cronjob that you configure in your hosting panel. See Order Sync & Cronjob for setup instructions. The recommended interval is every 15–30 minutes.

Navigate to Marketplace API > Lazada API to configure your Lazada seller account connection.

Enter your Lazada App Key and App Secret (from Lazada Open Platform).
Select your region (PH, TH, SG, MY, VN, or ID).
Click Save, then click Authorize to redirect to Lazada's OAuth page.
Log in to your Lazada seller account and grant access.

Token Management

The Lazada settings page shows your connection status and provides:

  • Refresh Token — Click to refresh the access token when it expires.
  • Test Connection — Verify the API connection is working.

Categories & Brands

Lazada Categories (Marketplace API > Lazada Categories): Fetch and cache the Lazada category tree. Search to find specific categories. Click a category to view its required and optional attributes.

Lazada Brands (Marketplace API > Lazada Brands): Brands are category-specific on Lazada. Fetch brands for specific categories. Brands are cached locally for fast autocomplete.

Profiles

Navigate to Marketplace API > Lazada Profiles.

Profiles let you mass-configure Lazada listings for products that share the same Lazada category and attributes.

Create a profile and give it a name.
Select which catalog categories and/or manufacturers this profile applies to.
Choose the target Lazada category and brand.
Set pricing markup (fixed amount + percentage).
Map Lazada attributes — enter static values or map them to ERP product fields.
Save — the profile auto-creates listings for all matching products.

Permissions Reference

Permissions use a parent-child hierarchy. Granting a parent permission automatically grants all its children. Conversely, having any child permission satisfies access checks for the parent group’s sidebar section.

Parent PermissionChild Permissions
Manage CatalogManage Products, Manage Categories, Manage Manufacturers, Manage Options
Manage SalesManage Orders, Manage Order Statuses
Manage Marketplace APIManage Shopee, Manage Lazada, Manage OpenCart
Manage SettingsManage Users, Manage User Groups, Manage Website Settings, Manage Error Log

Examples

  • A user with only Manage OpenCart can access OpenCart Settings and Profiles, but not Lazada or Shopee.
  • A user with Manage Marketplace API can access all marketplace features (OpenCart, Lazada, and Shopee).
  • A user with Manage Products can access the Products page but not Categories, Manufacturers, or Options.

The Administrator user group has all permissions enabled by default. Custom groups can have any combination of parent and child permissions.
