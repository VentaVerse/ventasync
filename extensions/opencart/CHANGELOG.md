# OpenCart changelog

## 0.31.0 (2026-10-23)

### Updates

- On a hosted server, store addresses must be public https addresses. Self-hosted installs are unchanged.
- The product group page no longer has the "Also listed on" column, so OpenCart no longer reads other channels.
- Some minor improvements.

## 0.30.0 (2026-10-07)

- First numbered release, opening the closed beta.
